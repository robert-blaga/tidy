# Philosophy

Agents don't necessarily need smarter models to become more useful. Often they need better memory systems.

The missing piece is durable taste: where *you* put books, invoices, screenshots, drafts, and odd little files that only make sense in the context of your machine — and, more broadly, how *you* want a kind of input handled when it shows up.

Tidy turns that taste into a small markdown wiki the agent can read, follow, and improve.

The pattern isn't tied to filing. Skills are type-level rules for handling a kind of input. The first batch you teach will probably be about files because that's the most universal first use case — but a skill can be about anything you keep handing to Tidy: an email address, a URL, a paste of text, whatever has a recognizable shape.

- durable local memory
- readable by humans
- executable by agents
- updated with approval
- portable across runtimes

The wiki is the durable part. Skills are executable memory. The runtime is replaceable.
