# Philosophy

Agents don't necessarily need smarter models to become more useful. Often they need better memory systems.

For filing, the missing piece is not another classifier. It is durable taste: where *you* put books, invoices, screenshots, drafts, and odd little files that only make sense in the context of your machine.

Tidy turns that taste into a small markdown wiki the agent can read, follow, and improve.

The pattern is bigger than filing:

- durable local memory
- readable by humans
- executable by agents
- updated with approval
- portable across runtimes

The wiki is the durable part. Skills are executable memory. The runtime is replaceable.
